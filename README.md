# 📑 Proyecto de Validación de Formulario 🖋
## ▶ Resumen
Este proyecto se basa en un formulario de registro, en el cual se deben rellenar los recuadros que te piden un usuario, un correo email, el país donde te encuentras, tu número telefónico, tu contraseña y la confirmación de la contraseña.
## ▶ Características
- *Estilo Futuristas*: Interfaz con efectos de desenfoque de fondo, bordes sutiles y sombras de neón.
- *Validación con REGEX*: Control estricto de entradas con Expresiones Regulares para el Username, Email, Teléfono y Contraseñas.
